# Brand imagery inspiration

[brand-imagery.webp](brand-imagery.webp) is a user-provided reference saved for inspiration when creating future images.

It is unrelated to agentic search. Saving this reference does not select it as a runtime asset or authorize image generation, integration, or changes to the approved interface design.
